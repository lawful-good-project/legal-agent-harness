# P24. Какая статья утратила силу и каким законом

Пункт 3 статьи 1 Федерального закона от 28.06.2022 № 193-ФЗ признаёт утратившей силу статью 1478 части четвертой ГК РФ. В поле `subject` записана изменённая норма, в `object` — реквизиты закона, которым внесена поправка. В официальной публикации сам пункт находится на странице 2. [Скан, с. 2](http://publication.pravo.gov.ru/document/0001202206280033?index=2)

Закон опубликован 28 июня 2022 года. Статья 2 устанавливает годичный срок после дня официального опубликования. Поправка действует с 29 июня 2023 года. В поле `effective_from` указана дата утраты силы статьи 1478. Значение `effective_to: null` означает, что у самой поправки не указан конечный срок. [Скан, с. 3](http://publication.pravo.gov.ru/document/0001202206280033?index=3) · [Карточка Роспатента](https://rospatent.gov.ru/ru/documents/fed-zakon-193-28062022) · [ВОИС](https://www.wipo.int/wipolex/ru/legislation/details/22112)

## Первый ответ и исправление

Для проверки взят короткий фрагмент с заголовком статьи 1 и её пунктом 3. Извлекатель нашёл две записи. Первая относится к заголовку, вторая — к строке с пунктом 3. На исходной версии программы `build_case` берёт первую запись. Ниже приведены значения, которые в результате попали в кейс. [Исходная версия извлекателя](https://github.com/lawful-good-project/legal-agent-harness/blob/a6211547ef330da0ddb521873ab04915f52d8c30/src/legal_agent_harness/validation_app.py)

| Поле | Первый ответ | После исправления |
|---|---|---|
| `subject` | статья 1 | ГК РФ ст. 1478 |
| `object` | fragment.txt | Федеральный закон от 28.06.2022 № 193-ФЗ |
| `predicate` | изменена | признана_утратившей_силу |
| `effective_from` | `null` | 2023-06-29 |
| `source.coordinate` | строка 4 фрагмента по счёту программы | ст. 1, п. 3 (с. 2), правило о вступлении в силу в ст. 2 (с. 3) |

## Как воспроизвести

Из корня `legal-agent-harness` выполните команды ниже. Первая покажет граф исходного извлечения, вторая проверит формат исправленного кейса.

```sh
python3 scripts/launch_validation_app.py examples/p24/fragment.txt \
  --authority 'Государственная Дума ФС РФ' --jurisdiction RU
python3 scripts/run_harness.py validate-cases examples/p24/case.jsonl
```

Журнал сохраняет первый ответ, замечание участника, исправление и решение по итоговой записи. Для проверки журнала нужен [валидатор курса](https://github.com/visualcomments/ip-law-course/tree/2d136c105f4a8b92078698ab0ebf30ae381f241b/legal-agent-calibration). Если обе рабочие копии лежат рядом, команду можно запустить из корня `legal-agent-harness`.

```sh
python3 ../ip-law-course/legal-agent-calibration/scripts/legal_calibration_session.py \
  validate --journal examples/p24/session.jsonl
```

Оба валидатора приняли материалы. В кейсе проверена одна запись, в публичном журнале — семь событий без ошибок, в том числе одно исправление и два отзыва эксперта. В последнем событии `expert_approved` имеет значение `true`.
