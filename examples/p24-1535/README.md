# P24. Каким законом дополнена статья 1535 ГК РФ

Пункт 11 статьи 1 Федерального закона от 05.12.2022 № 503-ФЗ дополнил статью 1535 ГК РФ пунктом 4. В конце нового пункта есть отсылка к пункту 2 той же статьи, где указаны основания и порядок оспаривания. Статья 2 закона устанавливает дату вступления в силу — 31.12.2022. [Официальная публикация, с. 6](http://publication.pravo.gov.ru/document/0001202212050044?index=6) · [С. 7](http://publication.pravo.gov.ru/document/0001202212050044?index=7)

В коротком фрагменте программа верно распознала номер статьи и тип изменения `дополнена`. В первой записи `subject` имел значение `статья 1535` без названия кодекса, а `object` содержал имя входного файла `fragment.txt`. После сверки с законом эксперт уточнил изменённую норму (`ГК РФ ст. 1535`), изменяющий акт (`Федеральный закон от 05.12.2022 № 503-ФЗ`) и дату, которую пропустила программа.

Для воспроизведения первого ответа и проверки исправленного кейса выполните из корня репозитория следующие команды.

```sh
python3 scripts/launch_validation_app.py examples/p24-1535/fragment.txt \
  --authority 'Государственная Дума ФС РФ' --jurisdiction RU
python3 scripts/run_harness.py validate-cases examples/p24-1535/case.jsonl
```

Публичный журнал можно проверить валидатором курса. Команда предполагает, что репозиторий `ip-law-course` лежит рядом с `legal-agent-harness`. [Валидатор курса](https://github.com/visualcomments/ip-law-course/tree/2d136c105f4a8b92078698ab0ebf30ae381f241b/legal-agent-calibration)

```sh
python3 ../ip-law-course/legal-agent-calibration/scripts/legal_calibration_session.py \
  validate --journal examples/p24-1535/session.jsonl
```

Валидатор harness принял исправленный кейс. Валидатор курса проверил все семь событий публичного журнала без ошибок. В журнале сохранены первое извлечение, замечание эксперта, исправление и одобрение итоговой записи.
