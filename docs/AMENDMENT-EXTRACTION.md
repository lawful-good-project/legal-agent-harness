# Извлечение изменений в российские НПА

Этот профиль harness предназначен для учебной калибровки агента, который
извлекает факты вида:

```text
документ-поправка → тип изменения → статья/пункт НПА → дата действия
```

Это не юридическая консультация. Любой результат требует проверки экспертом по
официальному источнику.

## Поля кейса

Для `source.doc_type = "amending_act"` используйте `authority`, `jurisdiction`,
`identifier`, точную `coordinate` и `effective_date`, если дата известна.

Ожидаемый результат содержит `norm_id`, `predicate`, `subject`, `object`,
`effective_from`, `effective_to`, `change_description` и `confidence`.

Допустимые типы изменения:

`изменена`, `дополнена`, `введена`, `изложена_в_новой_редакции`,
`признана_утратившей_силу`, `исключена`, `уточнена`.

## Минимальный прогон

```bash
python -m pytest -q
python scripts/run_harness.py validate-cases examples/amendments.jsonl
python scripts/run_harness.py replay \
  --cases examples/amendments.jsonl \
  --responses examples/amendments_responses.jsonl
```

Проверка дат является техническим гейтом согласованности: результат не может
начинаться раньше даты источника, а дата окончания не может быть раньше даты
начала. Это не заменяет проверку редакции нормы и вступления акта в силу.

## Рекомендуемый экспертный цикл

1. Указать официальный источник, юрисдикцию, редакцию и координату.
2. Получить черновой ответ агента.
3. Проверить номер статьи, тип изменения, дату и связь с изменяющим актом.
4. Явно перечислить ошибки в `expert_review`.
5. Сохранить исправление отдельным событием, не переписывая прежний ответ.
6. Завершить только после явного `expert_approved=true`.
