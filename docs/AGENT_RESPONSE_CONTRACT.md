# Контракт ответа агента

Профиль: [извлечение изменений в российские НПА](AMENDMENT-EXTRACTION.md).

Документ фиксирует, что агент получает от harness и что обязан вернуть. Примеры
ниже лежат в `examples/` и проверяются тестом, поэтому их можно вставлять в
промпт и использовать для replay-оценки.

Это учебная калибровка, а не юридическая консультация: реквизиты акта,
координату и даты эксперт сверяет с официальным источником.

## Что получает агент

Только `case_id` и `source`. Эталон `expected` агенту не передаётся.

```json
{
  "case_id": "contract-accept-001",
  "source": {
    "authority": "Государственная Дума ФС РФ",
    "jurisdiction": "RU",
    "doc_type": "amending_act",
    "identifier": "Федеральный закон от 01.07.2017 № 147-ФЗ",
    "coordinate": "ст. 1 п. 1",
    "effective_date": "2017-07-12"
  }
}
```

`coordinate` — место в изменяющем акте (статья, пункт, подпункт), по которому
эксперт находит исходный фрагмент. Полный текст акта в задание не входит.

## Что возвращает агент

Один JSON-объект, без markdown и пояснений вокруг него:

```json
{
  "status": "ok",
  "expected": {
    "norm_id": "гк-рф/ст.1252",
    "predicate": "дополнена",
    "subject": "ГК РФ ст. 1252",
    "object": "Федеральный закон от 01.07.2017 № 147-ФЗ",
    "effective_from": "2017-07-12",
    "effective_to": null,
    "change_description": "Статья дополнена пунктом 5.1 об обязательном претензионном порядке до иска о возмещении убытков или выплате компенсации.",
    "confidence": 0.9
  }
}
```

| Поле | Что писать |
|------|------------|
| `status` | необязательно; `ok` или `needs_revision` |
| `norm_id` | изменённая норма, например `гк-рф/ст.1252` |
| `predicate` | один из семи типов изменения из профиля |
| `subject` | что изменено |
| `object` | изменяющий акт: вид, дата и номер |
| `effective_from` | начало действия изменения: `ГГГГ`, `ГГГГ-ММ` или `ГГГГ-ММ-ДД` |
| `effective_to` | окончание действия или `null` |
| `change_description` | одно-два предложения своими словами |
| `confidence` | число от 0 до 1 |

Правила:

- `norm_id`, `predicate`, `subject`, `object` и `confidence` обязательны: без
  них ответ отклоняется до сравнения с эталоном.
- Остальные поля `expected` в этом профиле тоже заполняются: эталон
  сравнивается с ответом точно по всем своим полям.
- Других полей в ответе нет. Полный текст НПА, цитаты статей, персональные
  данные, e-mail, токены и локальные пути в ответ не включаются: норму
  определяют реквизиты акта и координата, а не текст.
- Координату агент не придумывает и не возвращает: она задана в `source`.

## Что нельзя принять: значение без coordinate

То же значение, но в `source` нет `coordinate`:

```json
{
  "case_id": "contract-reject-001",
  "source": {
    "authority": "Государственная Дума ФС РФ",
    "jurisdiction": "RU",
    "doc_type": "amending_act",
    "identifier": "Федеральный закон от 01.07.2017 № 147-ФЗ",
    "effective_date": "2017-07-12"
  }
}
```

Такой кейс отклоняется на валидации, до запуска агента:

```text
[contract-reject-001] source: обязательные поля отсутствуют/пусты: ['coordinate']
```

Пустая строка и пробелы отклоняются так же. Заглушка вместо координаты
(«не определена», «весь документ») приравнивается к её отсутствию: если
автоматическая проверка её пропустила, значение отклоняет эксперт.

## Совпадение не равно одобрению

Ответ, совпавший с эталоном, получает `approved: true`, но
`needs_expert_approval` всегда остаётся `true`: юридически результат
подтверждает только эксперт.

## Проверка

```bash
python scripts/run_harness.py validate-cases examples/agent_contract.jsonl
python scripts/run_harness.py replay \
  --cases examples/agent_contract.jsonl \
  --responses examples/agent_contract_responses.jsonl
python scripts/run_harness.py validate-cases examples/agent_contract_rejected.jsonl
python -m pytest -q tests/test_agent_contract.py
```

Третья команда должна завершиться с кодом `1` и назвать `coordinate`: файл
`examples/agent_contract_rejected.jsonl` намеренно не проходит валидацию.

Если пример вставлен в промпт как образец, не оценивайте агента на этом же
кейсе: совпадение будет подсказанным.
