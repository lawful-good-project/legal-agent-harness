# Экспертное извлечение изменений из НПА

[`law_extract_fixed.ipynb`](law_extract_fixed.ipynb) — самостоятельный Google Colab
ноутбук для извлечения изменений из документов и проверки экспертом в HTML-форме.
Исходник: [Colab](https://colab.research.google.com/drive/1JDWv7I3x0tQwWTCfXIdr_c55gzqGMBGR).

Откройте ноутбук в Colab и следуйте его ячейкам. HTML-форму нужно сгенерировать
заново после обновления ноутбука: ранее скачанные формы содержат прежний код.
Для прямой отправки введите HF-токен в защищённое поле формы. Результат отправки —
PR в датасет Hugging Face; это ещё не слияние в `main`.
Токен должен позволять создание PR в целевом датасете. При ограничениях браузера
скачайте JSON оценки и используйте ячейку публикации с секретом Colab `HF_TOKEN`.

Ноутбук — отдельная онлайн-интеграция: использует исходные зависимости `pypdf`,
`g4f` и внешние сервисы. Офлайн-адаптеры и зависимости самого harness не изменены.
В сохранённом ноутбуке удалены результаты выполнения и метаданные сессии Colab.
Логика извлечения, оценки и преобразования записей сохранена; исправлена отправка
в Hugging Face (область видимости комментария и формат запроса commit API).

Проверка отправки без сети:

```sh
python -m pytest -q tests/test_notebook_publish.py
```

Для выполнения JavaScript-проверок HTML-формы нужен Node.js; без него они пропускаются.
